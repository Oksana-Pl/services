Irish Wrestling Academy

A website for a wrestling academy, with training information, a timetable and contact details.

Explain what each class includes

The membership page separates children’s and adults’ training. The class description sits alongside a membership card, bringing the training format, included sessions and request action into one view.

Bring the training week into one view

The timetable organises sessions by day, time and training group. Keeping these details in a single table lets visitors compare children’s and adults’ sessions without opening separate pages.

Keep the mobile journey direct

The mobile homepage places the academy introduction and membership action before the class details. Stacked buttons and a compact menu preserve a clear route to classes on a narrow screen.
