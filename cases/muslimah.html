Online Platform for Muslim Women

A social network interface concept showing a personal profile, a photo feed and contacts.

Problem

Many Muslim women cannot fully use existing social platforms due to privacy, religious, and cultural reasons. There is a need for a women-only platform where users can communicate, share content, and sell services safely.

Solution

I designed a social platform with gender verification at registration that allows Muslim women to communicate, share content, run blogs, and sell services in a safe women-only environment.

Key Features

  • Gender verification at registration
  • User profiles
  • Messaging system
  • Content posting
  • Blog functionality
  • Selling services/products
  • Community interaction
  • User blocking and reporting
  • Payments

What I Learned

This academic project was completed as part of my UX design studies and demonstrates my approach to the full user-centred design process, from research and problem definition to prototyping and testing.

User research helps identify real user needs and define the correct product direction.
User flows help structure the platform and simplify navigation.
Design systems improve consistency and speed of design.
Components make the design scalable and reusable.
Prototyping helps test the interface before development.
Accessibility improves usability and inclusivity.
User testing helps identify problems and improve UX.
Iterations make the product more user-friendly.
